# touching-things

触れると、何かが起きる。ブラウザで遊ぶ、小さなインタラクティブ作品集。

## 01 — water / v0.1

画面いっぱいの静かな水面。触れると波紋が広がり、やがて消える。

- PC：マウス移動で小さな波紋、クリックで大きな波紋。
- スマホ・タブレット：タップで波紋、ドラッグで航跡。
- キーボード：Tabで水面に移動し、Enterまたはスペース。
- OSの「視差効果を減らす」設定に対応。静止時は描画を停止。

これは円を描いて水面を表現する最初の版です。波の物理的な干渉や屈折はまだありません。

## 手元で遊ぶ

`index.html` をブラウザで開くだけ。インストールやビルドは不要です。

## ファイル

`index.html`：ページの構造 ／ `style.css`：水の色と文字 ／ `water.js`：操作と波紋。

## GitHub Pagesで公開する

1. GitHubで `touching-things` という空の公開リポジトリを作成。
2. このフォルダのファイルをリポジトリのルートへ追加し、`main` に保存。
3. Settings → Pages → Build and deployment で **Deploy from a branch** を選択。
4. Branch を **main**、フォルダを **/ (root)** にして Save。
5. 公開完了後、Pages画面に表示されるURLで遊べます。

以後、main の変更が公開ページに反映されます。公開リポジトリには秘密情報を置かないでください。

## 次の遊びの候補

波紋の速さ・色を調整する、雨を降らせる、波の干渉を試す。
